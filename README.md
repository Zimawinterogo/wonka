# Whiteout 3.12.8 — Minecraft 1.21.1 / Fabric / Java 21

Версия 3.12.6 (сохранена в 3.12.7): автозакрывание обычных дверей через 210 игровых тиков и мягкое сопротивление ветра при движении против ветра в метель. Двери, привязанные к электросети Whiteout, исключены. Изменения из 3.12.5 (перевод рюкзака) сохранены, хотфикс WeatherDepth 3.12.4 тоже. Исправления пока прошли автономные проверки Java, но не полную сборку Minecraft.

**Новое в 3.12.7:** Undo зон, копирование параметров зон, отдельная позёмка, дверные засовы и баррикады для проёмов. Слияние патчей и полный чек-лист: [docs/3.12.7-MERGE-CHECKLIST.md](docs/3.12.7-MERGE-CHECKLIST.md). Новые патчи Codex прошли его проверку компиляции на 3.12.5, но объединённая версия 3.12.7 **полностью не компилировалась** — до проверки в Minecraft не считать её протестированным релизом.

История: ветка 3.12.4 основана на объединённых исходниках Whiteout 3.11.4. В ней присутствуют предыдущие улучшения погоды, звуков, пяти предметных текстур, локализации, аварийной лампы, сохранения электросетей и анимаций генераторов. Версия 3.12.1 добавила восстановление звука генератора после перезахода в мир. Версия 3.12.4 добавляет read-only проверку заряда резервной батареи аварийной лампы по ПКМ без вмешательства в сеть. Старый генератор по-прежнему требует 5 успешных рывков.

**Сборка для Windows:** `BUILD_3.12.8.bat` или `gradlew.bat --no-daemon clean build`. Для Linux/macOS: `./gradlew --no-daemon clean build`.

**Устанавливать только полный JAR:** `build/release/Whiteout-3.12.8-1.21.1.jar`. Промежуточный JAR из `build/libs` не является полным модом; Gradle сливает оверлей с `base/Whiteout-3.4.2-1.21.1.jar`, сохраняет исходные ресурсы и добавляет исправления байткода. Требуются JDK 21, Gradle 8.10.2 (скачивает wrapper) и доступ к зависимостям Fabric/Minecraft или заполненный Gradle-кэш.

**Состояние сборки:** в текущем окружении нет локального Gradle 8.10.2 и отсутствует доступ к серверу дистрибутива, поэтому JAR версии 3.12.8 здесь **не собран**; автономные проверки подтверждают лишь отдельные контракты, ресурсы и синтаксис. После сборки обязательно проверить игру и сделать копию мира. Подробности — [docs/3.12.1-GENERATOR-SOUND-RECOVERY.md](docs/3.12.1-GENERATOR-SOUND-RECOVERY.md).

**3.12.8 — объединение трёх веток:** общий детерминированный ветер сервера и клиента (скорость игрока и позёмка используют одно направление, силу и порывы), независимая позёмка, расширенные баррикады и исправленное выпадение досок при потере опоры. В мире сохраняется новый параметр `windStrengthPercent` (по умолчанию 35). Команда оператора `/whiteout atmosphere wind-strength 0..100` задаёт общую силу ветра; `/whiteout-wind status` диагностирует сопротивление. Клиентская `/whiteout-ground-snow wind` теперь сохраняет только автономную настройку и не подменяет ветер сервера; плотность меняется через `intensity`. Актуальный статус тестов и инструкции: [docs/3.12.8-INTEGRATION-NOTES.md](docs/3.12.8-INTEGRATION-NOTES.md). Значения трёх сложностей обсуждены отдельно и **не внедрены**.

Ветер можно отключить: `/whiteout atmosphere wind-movement false` (оператор), обратно включить: `true`. Автозакрывание действует на обычные двери (наследники DoorBlock), кроме привязанных к электрическим сетям Whiteout, и не захлопывает их на живых существ. Выключенная красным камнем дверь закрывается ванильной механикой; пока она запитана, автозакрытие её не принуждает.

Ниже сохранены технические инструкции и описание прежних механик.

Настройка старого здания (нужны права оператора):
```
/whiteout atmosphere old <ID_зоны_убежища> true
/whiteout atmosphere old-interval <ID_зоны_убежища> 45
/whiteout atmosphere old-sounds true
```
Отключение всех новых звуков здания: `old-sounds false`; конкретного здания: `old <ID> false`.
Интервал — минимум секунд при сильной метели, диапазон настройки 8–300. Для 45 секунд при сильной метели пауза 45–67.5 секунды, при слабой — длиннее. По умолчанию 30 секунд. Настройки хранятся в существующем whiteout-atmosphere.json данного мира.

Двери: прежняя команда `/whiteout atmosphere frozen-door` включает/выключает примерзание двери под прицелом. Порог 1600 тиков и стандартные три попытки сохранены. Добавлены локальные ледяные осколки и вспышка голубоватой пыли при разрушении наледи.

Генератор использует усиленную низкую моно-петлю generator_roar.ogg, подготовленную из существующего звука. Управление громкостью — штатный ползунок «Блоки». Звуки здания относятся к «Окружению».

Бинарная база base/Whiteout-3.4.2-1.21.1.jar необходима для существующего процесса сборки; она не является лишним старым релизом. ZIP содержит все исходники дополнения, ресурсы, базу, Gradle wrapper и актуальные тесты, без кешей и старых отчётов.

Диагностика для оператора уровня 2: `/whiteout power diagnostics`. Только просмотр; фильтры сетей, генераторов, щитков и зон, подробности и обновление. Привязанные устройства видны из конфигурации всех сетей; непривязанные — только в уже загруженных чанках в пределах четырёх чанков по X/Z от игрока. Зоны не имеют отдельной электрической привязки в существующей модели данных.

`gradlew.bat clean build` выполняет 18 поведенческих наборов Java. Затем `python -X utf8 tests/run_resources.py` запускает 8 наборов проверки ресурсов и итогового JAR. Python использует стандартную библиотеку; для дополнительной проверки PCM-петли нужен FFmpeg в PATH либо переменная `WHITEOUT_FFMPEG` с путём к исполняемому файлу. Офлайн-сборка требует заранее заполненного кэша Gradle.
