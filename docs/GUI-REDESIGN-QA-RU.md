# WHITEOUT 3.13.0 - визуальное обновление сюжетного лобби

## Статус
Экспериментальный редизайн интерфейса, отдельный от стабильной ветки. Пользовательский GUI выполняется клиентом; сохраняемые данные, сеть, сюжетные условия и разрешения не менялись.

## Что изменено
- Общий стиль лобби: холодный исследовательский интерьер, окно со снегом, свет лампы, деревянная доска и тонкие металлические панели.
- Отдельная зимняя иллюстрация для историй без загруженных автором фотографий.
- Более чёткий текст без уменьшения до 70%, шрифт minecraft:uniform для интерфейсных подписей.
- Кнопки с состояниями: обычная, наведение, нажатие, выбранная, недоступная.
- Экран участников: интерактивные слоты FIRST/SECOND, готовность, приглашение, Solo/Duo.
- Карточка истории и редактор получили новую компоновку, экраны фотографий и личных параметров используют те же материалы.
- Тестовое лобби показывает отдельную карточку Duo Test Mode, не изменяя карточку реального мира.

## Тестирование
1. На клиенте 1.21.1 Fabric с установленным модом открыть физическую сюжетную доску.
2. Проверить разрешения GUI Scale 2, 3, 4, включая маленькие окна.
3. Создать карточку, отредактировать название, описание, сохранить, переоткрыть.
4. Проверить галерею (до 5 фото, замену, перемещение, поворот).
5. Проверить Solo, приглашение Duo, две готовности и запуск.
6. Проверить Duo Test Mode с командным виртуальным напарником.
7. Перезайти в мир и проверить сохранение.
8. Отдельно проверить некорректный рендер частей доски 2x2 в мире: он НЕ входит в этот GUI-фикс.
