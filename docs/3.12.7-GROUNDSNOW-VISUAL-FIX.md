# Whiteout 3.12.7 — визуальная доработка позёмки

Основа: `Whiteout-3.12.7-GroundSnow-Visibility-Fix-Sources.zip`.
Номер версии **не изменялся**.

## Исправление

- Вместо квадратной текстуры частиц снежного блока используется отдельный тип `whiteout:ground_snow_wisp`.
- Три RGBA-спрайта с **прозрачными краями** подключены через стандартный атлас частиц Minecraft/Fabric.
- Частицы выглядят как тонкие прерывистые горизонтальные шлейфы, а не большие прямоугольники.
- Позёмка держится ближе к поверхности и появляется короткими порывами; снижен лимит активных частиц.
- Проверки снежной поверхности, укрытий и зон из предыдущего хотфикса сохранены.
- `/whiteout-ground-snow stats`, `/whiteout-ground-snow enabled` и `intensity` сохранены.
- Системы тумана, SnowRenderer, WeatherDepth, Iris-mixin и генераторы не затронуты.

- Java 21: синтаксический разбор всех 132 Java-файлов.
- Валидность JSON-ресурсов и PNG, прозрачность краёв, корректность пути атласа.
- Изменения ограничены двумя Java-классами и новыми ресурсами/тестом/описанием.

Полная Gradle-компиляция и игровой тест в данном окружении **не выполнялись** (зависимости Gradle не загружены и интернет недоступен).

## Ручная проверка в Minecraft 1.21.1

1. Собрать **новый** JAR командой `gradlew.bat assembleWhiteout --no-daemon` и заменить **старый** JAR (не держать два Whiteout одновременно).
2. Открыть копию мира с метелью, выполнить `/whiteout-ground-snow enabled true` и `/whiteout-ground-snow intensity 100`.
3. На открытой снежной площадке проверить низкие тонкие шлейфы **без видимых прямоугольных границ**.
4. Проверить команду `/whiteout-ground-snow stats` (созданные частицы > 0).
5. Проверить слои снега, крутые перепады высоты, закрытые помещения, стекло и отсутствие рендер-артефактов.
6. Проверить без шейдеров и с Iris/BSL. Проверить FPS, затем уменьшить интенсивность до 65% (значение по умолчанию в чистом конфиге).
7. Если появились отсутствующие текстуры/чёрно-фиолетовые частицы, проверить, что JAR содержит `assets/whiteout/particles/ground_snow_wisp.json` и все три PNG.

При появлении компиляционных ошибок прислать строки начиная с `error:` — не нужно пересылать весь `--stacktrace`.
