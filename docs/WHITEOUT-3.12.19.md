# Whiteout 3.12.19 — личная сборка

Основа: `fix/lake-story-3.12.18`, коммит `55108a827f0e62c840afd0d74db51529935fa902`.
Ветка обновления: `feature/whiteout-3.12.19`. Слияние в `main` не выполняется.

## Паспорт карты

- `/whiteout passport` открывает отчёт; требуется уровень прав 2.
- `/whiteout passport validate` сообщает число серверных ошибок и предупреждений и открывает отчёт.
- `/whiteout passport export` сохраняет отдельный `whiteout-passport.json` в корне мира и открывает отчёт.
- В существующей диагностике электросетей добавлена кнопка паспорта.
- Вкладки: сводка, зоны, электросети, атмосфера, диалоги, проблемы. Колесо мыши прокручивает список слева и подробности справа.
- Для проблем с координатами можно скопировать `/execute in <dimension> run tp @s ...`. Никакая команда автоматически не выполняется.

Паспорт использует существующий снимок `PowerDiagnostics` и копии конфигураций `GridManager`, адаптеры `ZoneFolders` и `ElectricDoors`, настройки `WorldAtmosphere` и новый адаптер чтения `DoorBolts`. Проверяются связи сетей, наличие устройств и ламп в загруженных чанках, измерения, доступные признаки повреждения конфигураций, геометрия зон, удалённые ссылки и возможные пересечения зон одинакового приоритета. Проверка пересечений использует ограничивающие объёмы: вырезы и точная форма требуют ручной проверки. Состояние топлива и предохранителя проверяется только по реально доступному устройству.

Отчёт показывает параметры ветра, старых зданий и их звуков, замерзающих дверей, электрических дверей и засовов. Незагруженные чанки отмечаются INFO и не загружаются. Паспорт не меняет сохранения и не исправляет конфигурации.

Клиент отдельно читает каталог диалогов, сцены и триггеры Director. Встроенные реплики и диалоги, используемые событиями сцен или эффектами триггеров, не объявляются неиспользуемыми. Предупреждение об отсутствии известной ссылки не доказывает отсутствие ручного вызова. Серверный экспорт не содержит клиентский каталог; это явно указано в интерфейсе и сообщении экспорта.

Лимиты: 2048 объектов и 2048 проблем, ограниченные текстовые поля и сетевые части по 16000 UTF-16 символов через существующий `SnapshotChunks`. При превышении лимитов установлен `truncated`; отчёт нельзя считать полной проверкой карты. Запросы ограничены одним в секунду на игрока.

## Отложенные инструменты

Массовая привязка ламп отложена: текущая операция `GridManager.lamp` последовательно изменяет список привязок, сохраняет конфигурацию и обновляет реальные блоки. Для массовой операции с переносом между сетями требуется отдельная транзакция с журналом отката и проверкой изменений между предварительным просмотром и применением.

Копирование шаблона сети также отложено: существующий `Config` смешивает физические привязки, сюжетные параметры, состояние аварий и сохранённые наблюдения. Отдельной модели безопасно копируемых настроек нет. Копирование этого объекта целиком нарушило бы требования; изменение модели сохранения в эту версию не включено.

## Музыка и воспроизводимая сборка

Все семь треков берутся из репозиторного `Whiteout-3.12.9-1.21.1.jar`, без перекодирования и изменения порядка. `tools/private_music.py` проверяет CRC каждой страницы OGG, последовательности, начало/конец потока и заголовки Vorbis. Ресурсы извлекаются в уже игнорируемый Git каталог:

```text
python tools/private_music.py Whiteout-3.12.9-1.21.1.jar --extract src/main/resources
gradlew.bat check assembleWhiteout --offline
python -X utf8 tests/run_resources.py
python tools/private_music.py Whiteout-3.12.9-1.21.1.jar --compare build/release/Whiteout-3.12.19-1.21.1.jar
```

Нужны Java 21 и заполненный кэш Gradle для `--offline`. Полный мод находится в `build/release/Whiteout-3.12.19-1.21.1.jar`, а не в `build/libs`. Музыка отдельными файлами в коммиты не включается.

## Проверки и ограничения

- `check`: 29 автономных Java-наборов, включая `PassportRulesTest` с сериализацией Gson и передачей большого отчёта частями.
- `foundationTests`: проверки баррикад, журнала озера, состояния устройств, кэша, жизненного цикла и сценарных настроек; Fabric SERVER bootstrap без запуска игрового мира.
- `assembleWhiteout`: полный мод объединяется с закреплённой базой 3.4.2.
- `tests/run_resources.py`: 15 наборов проверки ресурсов, локализаций, ABI и итогового JAR, включая `check_passport.py`.
- Проверки ресурсов для `data/whiteout/*.json` приведены в соответствие со сборщиком: семантически одинаковый JSON допускает различия CRLF/LF; изменённые данные по-прежнему отвергаются.
- Семь треков в конечном JAR сравниваются побайтово с источником. Версия `fabric.mod.json` — 3.12.19.

Игровой клиент, визуальная работа GUI, живая карта, Iris и BSL не тестировались. Полное декодирование аудио в PCM не выполнялось: ffmpeg отсутствует. Проверки формата и CRC OGG не заменяют прослушивание. Новые ASM-патчи, миксины, механики и изменения баланса не добавлялись.
