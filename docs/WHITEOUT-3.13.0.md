# Whiteout 3.13.0 — Conditional Dialogues 2.0

База: `feature/whiteout-3.12.19`, `5146801`. Рабочая ветка: `feature/whiteout-3.13.0-conditional-dialogues`. Merge в `main` не выполнялся.

## Использование

1. Откройте прежний каталог командой `/whiteout dialogues` (права уровня 2). Создайте обычные диалоги существующим редактором — например `generator_on`, `generator_off`, `generator_unknown`.
2. Нажмите **Маршруты → Создать**. Введите ID `lake_generator_reaction` и выберите запасной диалог `generator_unknown`.
3. Добавьте вариант: диалог `generator_on`, тип **Электросеть**, ID цели `main`, условие **да / включено**, приоритет `10`.
4. Добавьте вариант: диалог `generator_off`, тот же тип и ID цели, условие **нет / выключено**, приоритет `10`. Нажмите **Сохранить**.
5. Для проверки выберите маршрут и нажмите **Запустить**. Либо выполните `/whiteout dialogue play whiteout-route:lake_generator_reaction`.
6. Для сюжетного использования добавьте в обычную сцену Director событие **DIALOGUE**, в его значение вставьте `whiteout-route:lake_generator_reaction`. Кнопка **Скопировать ID** копирует именно эту ссылку. Длительность события остаётся параметром существующего Director.
7. Кнопка **Триггер** открывает прежнее окно привязки: область, NPC или сигнал. Оно создаёт обычную Director-сцену с DIALOGUE-событием маршрута. Сигнал вызывается прежней командой `/whiteout dialogue trigger whiteout-route:lake_generator_reaction`.

В списках работает колесо мыши. Нажатие варианта открывает его параметры. Больший приоритет проверяется раньше; при равенстве используется порядок списка, изменяемый кнопками **Выше / Ниже**. В окне выбора диалога введите поиск и нажмите **Поиск**. Изменения варианта сначала применяются в черновик; весь маршрут сохраняется отдельной кнопкой **Сохранить**.

Удаление маршрута требует подтверждения. Существующие сцены автоматически не переписываются: оставшиеся ссылки сообщат об отсутствии маршрута. ID сохранённого маршрута нельзя случайно переименовать; при создании дублирующий ID отвергается.

## Условия и выбор

- **Электросеть:** точный ID сети, питание есть/отсутствует. Только достоверное AVAILABLE-состояние из `WhiteoutWorldState`; CACHED не принимается за текущее состояние.
- **Генератор:** измерение и точные целочисленные координаты блока; работает/остановлен. Поддерживаются оба существующих вида генератора. Кнопка позиции игрока — только начальная подсказка; координаты нужно уточнить до блока генератора.
- **Погодная зона:** ID активной погодной зоны в позиции игрока, который запускает маршрут. Удалённый ID считается неизвестным.
- **Сильная метель:** существующий серверный признак `blizzard` активной погодной зоны. Клиентская сглаженная погода и визуальные эффекты не используются.
- **Сюжетная переменная:** существующая серверная переменная `Store.data.storyVariables`; сравнения выполняет `StoryRules`. Поддержаны boolean (`true`/`false`) и целые числа. Отсутствующее значение или несовпадение типов — UNKNOWN.

UNKNOWN не превращается в false, в том числе при отрицании условия. Первый подтвердившийся вариант выбирается после сортировки приоритетов. Если ни один не подтверждён — выбирается обязательный fallback. Если выбранный скрипт удалён на клиенте — используется существующий fallback; если удалён и он, выводится сообщение вместо исключения. Тексты, портреты, choices и auto-reply остаются объектами прежнего `DialogueManager`.

## Сохранения и интеграция

`<корень мира>/whiteout-dialogue-routes.json` содержит только параметры маршрутов и ссылки. `dialogues.json` не изменяется этой системой. Скрипты, портреты и библиотека Director по-прежнему клиентские: при распространении карты нужны те же файлы диалогов, которые требовались прежде. Маршруты хранятся в серверном мире; клиент не отправляет серверу предположения о питании или погоде.

Сохранение использует существующий `GridFileIO.writeAtomic`, проверяет ревизию и сначала пишет временный файл. Повреждённый файл сохраняется без изменений, маршруты блокируются до ручного исправления и повторного открытия мира. Обычные диалоги продолжают работать.

Лимиты: 64 маршрута, 1–16 вариантов на маршрут, ID маршрута до 64 символов `[a-z0-9_-]`, приоритет от -10000 до 10000, файл до 512 КиБ. Сохранение отдельного маршрута ограничено также 12000 символами JSON и 24000 байтами UTF-8. Редактирование требует уровня прав 2; воспроизведение сюжетного маршрута доступно обычному игроку.

Добавлен один клиентский Mixin к проверенным `DialogueManager.open/openDirector`: в базовом API нет callback до поиска скрипта. Новых ASM-патчей нет. Выбор выполняется по запросу на серверном потоке, без сканирования мира каждый тик и без принудительной загрузки чанков.

Пока маршрут разрешается сервером, последующие вызовы этих двух методов удерживаются в FIFO, максимум 32 вызова. Одновременные повторные активации одного маршрута объединяются; после завершения его можно активировать снова. Повторный сетевой ответ не воспроизводит реплику второй раз. Смена мира/отключение очищает очередь без повторного использования токенов. Завершённая Director-сцена не запускает запоздавшую реплику. При отсутствии ответа дольше 100 клиентских тиков запрос отменяется с сообщением.

Существующая HUD-очередь, оригинальный `DialogueScreen`, портреты и передаваемая длительность не заменены. Серверный выбор добавляет задержку сетевого обмена перед началом реплики; сцену Director нельзя считать приостановленной на это время. Точное поведение при большой сетевой задержке требует проверки в игре.

Паспорт карты распознаёт маршруты и их ссылки, не объявляет такие DIALOGUE-события ошибочными и учитывает варианты при поиске неиспользуемых реплик.

## Запущенные проверки

```text
gradlew.bat check assembleWhiteout -I qa/foundation.gradle -I qa/dialogue-routes.gradle foundationTests routeProbeClient routeProbeServer --offline --console=plain
gradlew.bat check assembleWhiteout --offline --console=plain
python -X utf8 tests/run_resources.py
python tools/private_music.py Whiteout-3.12.9-1.21.1.jar --compare build/release/Whiteout-3.13.0-1.21.1.jar
```

- 30 автономных Java-наборов, включая `DialogueRouteTest`: реальный выбор по приоритету и порядку, fallback, UNKNOWN и все состояния доступности WorldState, типы StoryRules, удалённые диалоги, FIFO/дубликаты/лимиты, очистка сессии, сохранение и повторное чтение, stale revision, ошибка записи, повреждённый/слишком большой файл, сохранность отдельного `dialogues.json`.
- `foundationTests`: прежние проверки баррикад, озера, устройств, кэша, жизненного цикла и сценарных настроек.
- `routeProbeClient`: реальное применение Mixin через Fabric CLIENT, оба обычных метода без маршрутов, старый поиск скриптов и метаданные aliases. Без графического окна и игрового мира.
- `routeProbeServer`: регистрация сети через Fabric SERVER и четыре roundtrip-проверки реальных кодеков пакетов без клиентских классов.
- 16 Python-наборов ресурсов/ABI/локализации/полного JAR. 75 защищённых классов механик побайтово совпадают с полной сборкой 3.12.19.
- Полный JAR объединён с базовым Whiteout 3.4.2. ZIP CRC, версия и необходимые классы проверены.

Семь оригинальных OGG извлечены существующим `tools/private_music.py` из `Whiteout-3.12.9-1.21.1.jar`. Проверены CRC страниц, последовательности и заголовки Vorbis; все семь файлов итогового JAR побайтово совпадают с источником. Перекодирование и плейсхолдеры не использовались. Отдельные аудиофайлы не включены в Git-коммиты.

## Требует проверки непосредственно в Minecraft

- Создание/редактирование маршрута мышью, масштаб GUI, русский/английский интерфейс.
- Реальная карта: включение/выключение сети и генераторов, выгрузка чанков, переход между погодными зонами, изменение сюжетных переменных.
- Director-сцены с несколькими событиями, interactive choices, портретами, пропуском сцены и большой сетевой задержкой.
- Подключение нескольких игроков, перезапуск настоящего сервера и повторное открытие сохранения.
- Iris и BSL, визуальные эффекты и прослушивание музыки. Полное PCM-декодирование не выполнялось: ffmpeg отсутствует.

Эти проверки не подменяются Fabric bootstrap и автоматическими тестами. Озёрная сцена и её реплики, баланс, электричество, Winter Crisis Engine, рюкзак, Forest Loop, погода, хоткеи и портреты не изменялись.
