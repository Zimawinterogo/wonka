# Whiteout: аудит roadmap, 2026-11-03

База: `feature/whiteout-3.13.0-conditional-dialogues`, `96773825e34877fb27b8fa13e0fd78e72de44f7d`.
Версия 3.13.0; Minecraft 1.21.1, Fabric Loader 0.18.4 / API 0.116.17,
Java 21, Gradle wrapper 8.10.2, Loom 1.8.13. Рабочая ветка:
`feature/whiteout-roadmap-stabilization`. Исходное рабочее дерево чистое.

Это overlay поверх `base/Whiteout-3.4.2-1.21.1.jar`. Поэтому проверены не только
исходники, но и инструкции обработчика `WhiteoutNetwork.handle` в базовом JAR.
Локальные бинарные файлы повторно использованы только после совпадения Git blob SHA
с актуальной веткой. Пользовательская копия на другом диске не изменялась.

| Область | Статус | Доказательства / следующий шаг |
|---|---|---|
| Сетевое сюжетное состояние | BROKEN | STORY_COMMIT принимает клиентские conditions/actions; EVENT_DONE/REMOVE_COMPLETED_EVENT и ACTOR_* не проверяют полномочия в handle. Нужны серверные определения и запрет неподтверждённых изменений. |
| WORLD Story State | PARTIAL | Store.Data уже содержит storyVariables/objectives/completedEvents/checkpoints. Новый параллельный Store не нужен. Нет общего транзакционного слоя для всех путей записи. |
| PLAYER-прогресс / Duo | PARTIAL | Есть общая серверная синхронизация, но это не полная система персонального сюжетного прогресса. |
| World State / Conditions | DONE / PARTIAL | WhiteoutWorldState и WinterCrisisConditions уже есть. Накопленный холод остаётся клиентским и не должен выдаваться за серверный факт. Полный набор условий roadmap ещё отсутствует. |
| Winter Crisis / Director | PARTIAL | Координатор ограничивает очередь и нагрузку; CrisisRuntime запускает только диагностические callbacks. Фазы сюжетного кризиса и восстановление активного кризиса не реализованы. |
| Чёрная ночь | MISSING | Полноценного серверного сценария в проверенных исходниках нет. |
| Тьма у озера | PARTIAL | LakeStory, журнал блоков, reset, серверные проверки и утверждённые LakeDialogueLines уже существуют. Игровая проверка обязательна. |
| Условные диалоги | DONE / PARTIAL | 3.13.0 содержит серверный выбор, очередь, редактор, сохранение и тесты. Скрипты и основной Director остаются клиентскими. |
| Портреты | PARTIAL | StoryPortraits уже есть; полный контракт обновления скинов требует проверки. |
| Map Passport | PARTIAL | MapPassport/PassportRules/Collector уже существуют; не создавать повторно. Полнота метаданных roadmap требует отдельной доработки. |
| Электросети | PARTIAL | Сети, генераторы, двери, выключатели, сохранение и диагностика существуют. Массовая привязка с preview/undo не завершена. |
| Plot / Forest Loop | PARTIAL | Базовый JAR содержит Plot/ForestRoute; overlay исправляет stamp. Полный аудит транзакций и Duo-переходов ещё нужен. |
| Monster addon | MISSING | Отдельного Gradle subproject в актуальном дереве нет. |
| Баланс / атмосфера / GUI | PARTIAL | Реализован большой объём прежних изменений; все контрольные значения и визуальные требования ещё не подтверждены. |
| Radio 2.0 / Director Triggers | PARTIAL | Существующий контент сохраняется. Полный серверный контракт roadmap не готов. |
| CI | PARTIAL | Есть Java regressions, qa/foundation.gradle, Fabric probes, Python resource checks. GitHub Actions отсутствует. |

Матрица отражает пределы короткого аудита, а не результат игрового тестирования.

существующего Store. Затем проверить интеграцию и только после этого расширять
